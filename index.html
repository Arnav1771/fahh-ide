Your code broke.

Fahh Editor is a Monaco-based code editor for Windows, macOS and Linux. When a language server reports an error in your file, it plays one short, unforgettable sound, then stays quiet for three seconds, so a cascade of forty errors is still one sound.

      [Under the hood]

      From a squiggle to a sound.

      Four pieces, in the order a message travels. The line under each title is a real path and value in the repository.

      01

      The language server

      src-tauri/src/core/lsp_client.rs // stdio JSON-RPC // 18 languages

      Rust starts the server for the file's language and relays each message it sends to the window.

      02

      LspBridge

      src/components/LspBridge // textDocument/publishDiagnostics

      Turns diagnostics into Monaco markers, then checks whether any of them is an error.

      03

      One shared cooldown

      src/lib/cooldown.ts // DEFAULT_COOLDOWN_MS: 3000 // no queueing

      Module-level, for the life of the app. A refused call does not extend the window.

      04

      The sound

      src/lib/fahh.ts // AudioContext.decodeAudioData // assets/fahh.mp3

      Decoded once at start-up and played from memory, so the sound follows the squiggle with no delay.

      [FAQ]

      Asked, loudly.

      Does it really play on every error?

      On every error-severity diagnostic, at most once per cooldown window. The window is 3 seconds by default and set by sfx_cooldown_secs in ~/.fahh/config.json. Warnings, information and hints never play.

      Can I turn the cooldown off?

      Set sfx_cooldown_secs to 0 and every error message plays. Choose 0 in the simulator above to hear what that is like.

      Is it Electron?

      No. The shell is Tauri 2: a Rust core and the operating system's own web view, with Monaco as the editor.

      Which languages get squiggles?

      Rust, TypeScript, JavaScript, Python, Go, C, C++, Java, Lua, Ruby, HTML, CSS, JSON, YAML, C#, Dart, Kotlin and Bash, once that language's server (pyright, rust-analyzer, gopls, clangd and so on) is installed and on your PATH.

      Is there autocomplete?

      Monaco's built-in completion works. Completion, hover and go-to-definition from the language servers are still being wired up.

      Why does my system warn about the installer?

      The builds are not code-signed. Signing needs a paid certificate; until then Windows and macOS ask before the first launch. The source and the build workflow are public if you would rather build it yourself.

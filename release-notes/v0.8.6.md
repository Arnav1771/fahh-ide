## Fahh Editor v0.8.6

Fahh Local's Continue works again after a turn stops at the step limit; stuck sessions recover by themselves.

### Install

```powershell
# Windows (PowerShell)
irm https://fahhide.duckdns.org/install.ps1 | iex
```

```bash
# macOS (installs Fahh Editor.app) and Linux x64 (AppImage as ~/.local/bin/fahh, plus an app-menu entry)
curl -fsSL https://fahhide.duckdns.org/install.sh | bash
```

### Fixed
- **Fahh Local: Continue works after a stopped turn.** A turn that ended between a tool call and its result (the step limit, Stop, an error) left the session unusable: every next message failed with a provider 400 about tool_use without tool_result. The session now saves the results too, and any unanswered call is closed off before the next request, so stuck sessions recover on their own.

## Fahh Editor v0.8.0

Real language features, a terminal you can rely on, a proper Agent mode, and every theme fixed.

### Install

```powershell
# Windows (PowerShell)
irm https://fahhide.duckdns.org/install.ps1 | iex
```

```bash
# macOS (installs Fahh Editor.app) and Linux x64 (AppImage as ~/.local/bin/fahh, plus an app-menu entry)
curl -fsSL https://fahhide.duckdns.org/install.sh | bash
```

### Added
- **Language features from your language servers:** completion, hover, go to definition (across files), find references, rename (with undo, even in files you haven't opened), signature help, quick fixes and inline type hints, for Python, TypeScript, Rust and the other languages Fahh starts a server for (#121).
- **ESLint, Ruff and Tailwind** language servers when they're installed; **Emmet**, import-path completion, linked tag editing, a **TODOs** view, and previews that reload on save (#121).
- **Agent mode, redesigned:** sessions on the left, the conversation with folded tool steps in the middle, and a Changes / Plan / Context inspector on the right (Accept all, checkpoints with Rewind). A new session starts with suggestions for your project (#124).
- **The Explorer updates live** when files change on disk, including WSL folders; open tabs reload or warn (#126).

### Fixed
- **Terminals:** new terminals start even while another is busy; they open at the right size and follow resizes; the mouse wheel scrolls (Shift+wheel always does); 🗑 closes the tab and ends everything running in it; split panes show which shell they are (#122).
- **New Window and `fahh <folder>` opened a white, frozen window.** Fixed (#122).
- **Themes:** the canvas, its nodes, the terminal and panels follow Gold, Dark, Light and the others, with readable contrast; menus no longer have a line drawn through them (#126).

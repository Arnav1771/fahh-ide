## Fahh Editor v0.7.3

Python and notebooks work like they do in VS Code, the agent's model pickers are one consistent list, and two terminal bugs are fixed.

### Install

```powershell
# Windows (PowerShell)
irm https://fahhide.duckdns.org/install.ps1 | iex
```

```bash
# macOS (installs Fahh Editor.app) and Linux x64 (AppImage as ~/.local/bin/fahh, plus an app-menu entry)
curl -fsSL https://fahhide.duckdns.org/install.sh | bash
```

### Added
- **Run Jupyter notebooks in the editor.** ▶ Run on each cell, Run all, Interrupt and Restart, with a live kernel per notebook (variables persist). pandas tables, matplotlib plots and tracebacks appear as they stream, and are saved into the `.ipynb`. A **kernel picker** lists your `.venv`, conda envs and other Pythons and remembers your choice. Only `ipykernel` is needed; if it's missing, Fahh shows the exact install command (it never installs anything silently) (#112).
- **Accept all / Reject all** in the agent's "Review: N files changed" (#114).

### Changed
- **Python uses the project's `.venv`.** Run (Ctrl+F5), Debug and notebooks pick Settings > Python > Interpreter, then `.venv` / `venv` in the folder, then `python` on PATH. The Run header shows which: `[python · .venv]` (#112).
- **Fahh Local models come live from your provider.** No more hardcoded lists. Groq, OpenAI and the other built-in providers no longer show a base URL. **Custom (OpenAI-compatible)** takes your own base URL and an optional key. A rejected key says "Key rejected (401)" with Retry (#111).
- **One model picker everywhere:** settings Model, Fast model, the panel header and the welcome tour all use the same live list, with "Type a model name…" on each (#114).

### Fixed
- **Canvas terminal selected the wrong line.** On the Spatial Canvas, dragging to select (and double-click and right-click) landed a row above or below at any zoom except 100% (#113).
- **"Running scripts is disabled on this system"** in Fahh's PowerShell terminals: your profile and `.venv\Scripts\activate` now load. Fahh starts its own PowerShell terminals with `-ExecutionPolicy RemoteSigned` for that terminal only; your system policy is untouched. Settings > Terminal switches it back (#113).

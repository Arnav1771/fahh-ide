## Fahh Editor v0.8.5

Fahh Local gets a usage card, live step progress and real markdown, plus an Update button in the status bar.

### Install

```powershell
# Windows (PowerShell)
irm https://fahhide.duckdns.org/install.ps1 | iex
```

```bash
# macOS (installs Fahh Editor.app) and Linux x64 (AppImage as ~/.local/bin/fahh, plus an app-menu entry)
curl -fsSL https://fahhide.duckdns.org/install.sh | bash
```

### Added
- **Fahh Local usage card.** /usage shows the session's total tokens, the in/out split and the model and tool call counts; /context and /model use the same tiles. Click the token badge to open it.
- **Live progress.** While Fahh Local works, the panel lists each step as it happens, with elapsed time and a step count.
- **Step limit, no dead end.** At the 25-step limit: Continue, Summarise so far, or Usage.
- **Update button.** When a newer Fahh is out, a gold button appears in the status bar with the download.

### Fixed
- Fahh Local replies render markdown properly: tables, lists, headings, quotes and links.
- Side bars such as Fahh Local are easy to resize (a wider grab area on the drag handle).
- The effects toggle says "Epic effects" and explains what each level does.

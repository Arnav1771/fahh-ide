## Fahh Editor v0.6.8

Polished installers from **Stealth Keqing**.

### Install

```powershell
# Windows (PowerShell)
irm https://fahhide.duckdns.org/install.ps1 | iex
```

```bash
# macOS (installs Fahh Editor.app) and Linux x64 (AppImage as ~/.local/bin/fahh, plus an app-menu entry)
curl -fsSL https://fahhide.duckdns.org/install.sh | bash
```

The installers are not code-signed yet, so Windows SmartScreen ("Windows protected your PC": More info, Run anyway) or macOS Gatekeeper may warn on first run.

### Changed
- **Installers** name **Stealth Keqing** as the publisher: Add/Remove Programs, the MSI, and the app's file details (company, copyright). New setup-wizard artwork for the .exe and .msi, the app icon on the installer, the MIT license page, and a **Stealth Keqing** folder in the Start Menu (#100).
- One-line installs for every system in the README and install guide (#99).

Everything else is as in [v0.6.7](https://github.com/Arnav1771/fahh-ide/releases/tag/v0.6.7): accounts with email verification, git in the status bar, Outline, Timeline, Settings search.

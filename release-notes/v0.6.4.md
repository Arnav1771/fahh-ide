## Fahh Editor v0.6.4

Windows and WSL folders work, notebooks open, files have real icons, and every feature that was only pretending is gone. A Tauri 2 desktop editor with Monaco, a 2D spatial canvas, the in-editor Fahh Local agent, and the fahhhh.mp3.

### Fixed
- **WSL folders work on Windows.**
  - **Terminal:** in a `\\wsl.localhost\...` folder, every terminal command used to run in `C:\Windows`. Now it runs in WSL, in that folder.
  - **Run:** files in WSL failed with `os error 267`. They now run inside the distro (`python3`, `node`, `go run`, ...) (#77).
- **+ Shell really switches shell.** PowerShell, Command Prompt and Bash (WSL) used to only rename the tab (#77).
- **New windows can open things.** Windows opened with Ctrl+Shift+N, or by a second `fahh <path>`, had no permissions (#77).
- **Open Folder** opens one dialog, not two, and shows an error if it fails (#77).
- **Closing a tab always asks** about unsaved changes, whether from the tab, the menu, the palette or Ctrl+W (#80).
- **A blank-screen crash is gone.** It happened on Ctrl+K after opening a notebook; Ctrl+K belongs to Monaco again (#80).
- **Shortcuts:** Ctrl+W closes the tab and Ctrl+N opens a new file. Both used to be labels only (#80).

### Added
- **Jupyter notebooks (.ipynb)** open in a read-only viewer: markdown, highlighted code, outputs, images and errors (#78).
- **Real file icons** (a Material Icon Theme subset, MIT) in the explorer, tabs, breadcrumbs, Quick Open and search, with light-theme variants (#79).
- **VS Code workspaces:** `.code-workspace` files load, including comments, relative folders, `vscode-remote://wsl+` and `file://` folders, and `files.autoSave`. `fahh team.code-workspace` works from the terminal (#77).

### Removed
These looked like features but had nothing behind them (#80):
- Composer (Ctrl+I), Inline Edit (Ctrl+K) and ghost-text completions;
- REA Code Analysis;
- the Ports and Output panels;
- the terminal's "Fix with AI" button and image paste.

The real AI feature is the **Fahh Local** agent panel.

### Known issues
- Ctrl+W on a tab can log a harmless Monaco "Canceled" error in the console.
- Syntax errors only fahh without a language server for Python and Rust. Other languages still need their language server.

## Fahh Editor v0.8.1

Source Control grows up, and Roundtable remembers your tables.

### Install

```powershell
# Windows (PowerShell)
irm https://fahhide.duckdns.org/install.ps1 | iex
```

```bash
# macOS (installs Fahh Editor.app) and Linux x64 (AppImage as ~/.local/bin/fahh, plus an app-menu entry)
curl -fsSL https://fahhide.duckdns.org/install.sh | bash
```

### Added
- **Source Control, much closer to VS Code:** pick which repository to show when a folder holds several; initialise a repo from an empty folder; switch, create and delete branches from the status bar; fetch, pull, push and publish a branch with plain-English errors (sign-in, rejected push, offline, conflicts); stash, list and pop; stage, unstage and discard single change blocks; amend the last commit; resolve merge conflicts (accept current, incoming or both) and the commit waits until they're resolved (#129).
- **Roundtable: rejoin your last table.** Fahh remembers your recent tables and offers "Rejoin" with your seat and history; it says clearly when a table has ended and reconnects by itself after a drop (#128).

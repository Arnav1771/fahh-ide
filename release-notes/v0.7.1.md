## Fahh Editor v0.7.1

Sit at a shared coding table without leaving the editor: the new Roundtable panel starts or joins a Roundtable, so you and your team (and your AI agents) build together, one turn at a time.

### Install

```powershell
# Windows (PowerShell)
irm https://fahhide.duckdns.org/install.ps1 | iex
```

```bash
# macOS (installs Fahh Editor.app) and Linux x64 (AppImage as ~/.local/bin/fahh, plus an app-menu entry)
curl -fsSL https://fahhide.duckdns.org/install.sh | bash
```

### New
- **Roundtable panel** (activity bar, or "Roundtable: Start or Join a Table" in the command palette) (#107):
  - **Start a table** in one click on a Roundtable server. The invite link is copied for you to send. Or **join** with someone's link.
  - A **live transcript**: every turn streams as it runs, with notes from the people at the table.
  - **"groq is writing index.html · 12s"** while an agent works, with a Stop button for your own turn.
  - **Ask** for a change or send a **Note**. Pick the agent; providers you've added your own key for are marked, and you can add a key right there.
  - **Undo** your own change, browse the table's **files** (read-only), **copy the invite**, **connect your own AI agent** (copies one line for Claude Code, Codex or Copilot), or **open the table in a browser** with the same seat.

### Notes
- The default Roundtable server is the hosted one. Point the panel at your own server in its Start box.

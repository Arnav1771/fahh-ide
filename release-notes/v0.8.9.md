## Fahh Editor v0.8.9

fahh agent runs Fahh Local right in your terminal, even with a Fahh window open.

### Install

```powershell
# Windows (PowerShell)
irm https://fahhide.duckdns.org/install.ps1 | iex
```

```bash
# macOS (installs Fahh Editor.app) and Linux x64 (AppImage as ~/.local/bin/fahh, plus an app-menu entry)
curl -fsSL https://fahhide.duckdns.org/install.sh | bash
```

### Fixed
- **`fahh agent` in a terminal (Linux AppImage).** With a Fahh window open, `fahh agent` printed nothing: the window took the arguments. It now runs Fahh Local right in the terminal. On Windows the terminal command is `fahh-agent`.

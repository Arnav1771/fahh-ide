## Fahh Editor v0.7.2

A fix for the Roundtable panel that shipped in v0.7.1: it no longer crashes when a turn starts streaming.

### Install

```powershell
# Windows (PowerShell)
irm https://fahhide.duckdns.org/install.ps1 | iex
```

```bash
# macOS (installs Fahh Editor.app) and Linux x64 (AppImage as ~/.local/bin/fahh, plus an app-menu entry)
curl -fsSL https://fahhide.duckdns.org/install.sh | bash
```

### Fixed
- **Roundtable panel crashed** as soon as a turn started streaming output, right after you pressed Ask (`TypeError: t is not a function`). The turn still ran on the table, but the panel was replaced by an error. Found by end-to-end testing the installed v0.7.1 on Windows; current WebView2 returns a Promise from `scrollIntoView`, which a panel effect handed back to React as its clean-up (#109).
- A new test fails the build if any panel effect returns a DOM call's value, so this class of crash can't come back (#109).

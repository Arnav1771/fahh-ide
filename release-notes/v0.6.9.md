## Fahh Editor v0.6.9

Bring your own AI endpoint, working window buttons, and a sturdier Fahh Local.

### Install

```powershell
# Windows (PowerShell)
irm https://fahhide.duckdns.org/install.ps1 | iex
```

```bash
# macOS (installs Fahh Editor.app) and Linux x64 (AppImage as ~/.local/bin/fahh, plus an app-menu entry)
curl -fsSL https://fahhide.duckdns.org/install.sh | bash
```

### New
- **Your own AI endpoint.** Fahh Local settings > Provider > **+ Add your own endpoint…**: any OpenAI-compatible server (vLLM, LM Studio, llama.cpp, LiteLLM, a company gateway) or an Anthropic endpoint. **Save and fetch models** lists its models right away; saved endpoints sit under **Your endpoints** (#103).
- **Subagents, documented.** The main agent can hand jobs to the built-in `explore`, `reviewer` and `planner` subagents, or to your own in `.fahh/agents/`; each runs as its own card (#103).

### Fixed
- **Minimize, Maximize and Close in the title bar** did nothing in every window. They work now (#102).
- **Fahh Local on Groq**: the preset offered models Groq retired; it now offers `openai/gpt-oss-120b`, `gpt-oss-20b` and `qwen3.8-27b` (#102).
- **Rate limits** no longer fail the reply: Fahh Local waits as the provider asks (up to a minute) and retries; daily caps are still reported (#102).
- **Free-tier output caps** ("Limit 1000, Requested 2048"): the request is resent within the cap (#102).
- An agent that ended with no answer after using its tools is asked once to answer; a search with an empty path searches the whole project (#102).

### Tested on Windows (installed build)
Three windows on three projects with Fahh Local answering in each at once, canvas, window buttons, your own endpoint with model fetching, and a subagent run. About 510 MB for one window and 1.0 to 1.4 GB for three.

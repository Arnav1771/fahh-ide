### New
- **Run and Debug** (Ctrl+Shift+D), rebuilt on the Debug Adapter Protocol. Breakpoints in the gutter (click or F9), F5 to start or continue, F10 / F11 / Shift+F11 to step, Variables you can expand, Call Stack, and a Debug Console you can evaluate in. Python (debugpy), Go (Delve) and C/C++/Rust (lldb-dap); `.vscode/launch.json` works as in VS Code. Ctrl+F5 runs without debugging (#92).
- **A real terminal.** Every tab is a real shell (PowerShell, Command Prompt, Git Bash, WSL; bash/zsh on Linux and macOS): interactive programs, colours, Tab completion, Ctrl+C. New, split, a default profile, and Run Task from `.vscode/tasks.json` (#92).
- **Agent mode.** The Agent | Editor switch (top left) turns the window into the Fahh Local chat with your sessions on the left. Ctrl+Shift+A searches sessions; Ctrl+Shift+P works everywhere (#92).
- **Remote Explorer**: WSL distros (open a home folder, open a terminal), SSH hosts from `~/.ssh/config`, and running Docker containers (#92).
- **DeepWiki**: right-click a symbol, See Wiki: where it is defined, its documentation, every usage, and an AI explanation (#92).
- **Colour themes from Open VSX** really install now (Install used to only record the click). Other VS Code extensions say why they cannot run (#92).
- **Accounts and settings sync** (Settings > Account): create an account, upload your settings and theme, download them on another machine. Optional; Fahh works fully without one. Forgot password by email code, newsletter opt-in, and a What's new popup for announcements (#93).
- **Dockable layout**: drag Explorer, Fahh Local and the panels anywhere, split editors, a saved layout per folder, Reset Layout (#85).
- **Fahh Local**: sessions, modes, slash commands, `/loop` and subagents (#86).
- **Onboarding**: an interactive first-run tour, your own error sound, Check Setup, and a quiet daily update check (#89).
- **Everyday editing**: tabs in most-recently-used order, back/forward, Open Recent with session restore, explorer drag-and-drop, a Settings page (Ctrl+,), app dialogs instead of browser pop-ups (#87).

### Fixed
- The Explorer follows the disk: folders made in the terminal, by `git clone`, `npm create` or the agent appear without a refresh (#92).
- Every view shortcut works (Ctrl+Shift+E / F / G / X / D); they were only tooltips (#92).
- `fahh <file>` opens a tab in the running window instead of a new window (and ~160 MB) per file (#90).
- Windows MSI build (fahh-agent was packaged twice); notebooks and files saved with a UTF-8 BOM open correctly (#88).
- A blank window after restoring a WSL session (#88).

### Tested on Windows (installed build)
Debugging, the terminal (python, npm, a Vite dev server opened in the built-in browser, git, Git Bash, WSL), cloning a repo then fixing, running, committing and pushing it from inside Fahh, the canvas and previews, accounts, and WebView memory (about 500 to 640 MB with GPU, 390 to 510 MB with `--disable-gpu`, no leak over repeated open/close).

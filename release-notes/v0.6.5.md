# Fahh Editor v0.6.5

Release v0.6.5 brings **Fahh Local** (our sovereign multi-turn autonomous coding agent), a **dockable multi-panel workspace**, **single-instance CLI opening**, an **interactive onboarding tour** with custom error sound selection, and major Windows fixes.

---

## What's New

### 1. Single-Instance CLI Opening (`fahh <file>`)
Opening files from the command line (`fahh src/main.rs`) now connects to your running Fahh Editor instance and opens the file in a new tab within the active window. This eliminates unnecessary multi-process overhead, saving upwards of 750MB RAM compared to spinning up a new WebView2 window per file.

### 2. Fahh Local Autonomous Agent
- Native multi-turn agent sessions directly in the sidebar panel.
- Flexible execution modes with explicit permission boundaries.
- Built-in slash commands (`/help`, `/clear`, `/loop`, `/doctor`).
- Subagent dispatch capability for parallel codebase exploration and testing.

### 3. Dockable Workspace Layout
- Drag and drop panels anywhere: Explorer, Fahh Local, terminal, and output panes.
- Split editors vertically and horizontally with synchronized scrolling and active tab indicators.

### 4. Interactive Onboarding & Custom Audio Engine
- 3-step skippable welcome tour on first launch.
- Error sound selector: Pick your preferred audio tone with instant preview, or load custom sounds.
- **Check Setup** diagnostic modal verifying your local compilers, runtimes, and LLM providers.
- Silent daily release update notifications.

### 5. Windows & Reliability Hardening
- Fixed WiX MSI build by eliminating duplicate bundling of `fahh-agent`.
- Preserved UTF-8 BOM markers on Windows file saves without encoding errors.
- Session restore for recent projects, smooth tab closing, and high-contrast Fahh Light theme fixes.

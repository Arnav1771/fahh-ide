### What's new
- **Multiple terminals:** session tabs, a shell switcher, and a split view (#64, #65).
- **Search across the workspace:** global search, multi-file replace, and line/column in the status bar (#70).
- **New window in one click:** a titlebar button and a global shortcut, with separate sessions per window (#63, #69).
- **Icon themes:** an icon theme engine with Open VSX store install and activation, and a theme selector (#66).
- **Fahh Local chat:** copy buttons on code blocks, prompt queueing, steering a running turn, auto-save, and workspace management (#71).
- **Canvas and PDF:** the canvas opens centered at 1.0 zoom and sharp, and PDFs get native viewer hints (#63, #67).

### Known issues
- The error sound plays for TypeScript, JavaScript, JSON, CSS and HTML as you type. Other languages are silent unless a language server for them is running.
- Ctrl+L toggles the Fahh Local panel even inside the editor, which hides the editor's select-line. Fixed on main after this release (#72).

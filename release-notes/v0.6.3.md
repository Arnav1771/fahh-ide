The installers are not code-signed yet, so Windows SmartScreen or macOS Gatekeeper may warn on first run.

### Fixed
- **Python and Rust errors fahh without a language server.** Syntax errors now underline, show in Error Lens and play the sound. Rust is parsed in-process; Python is compiled (never run) by your installed interpreter, so the verdict matches your Python. Once pylsp or rust-analyzer is ready, they take over (#74).
- **Crashed runs fahh.** A run that exits with an error plays the sound; stopping a run does not (#72).
- **Ctrl+L selects the line again** inside the editor. Ctrl+Shift+A still toggles Fahh Local from anywhere (#72).
- **CI is green** on main again (#72).
- **Release notes** now come from `release-notes/<tag>.md`, or are generated from merged PRs, instead of repeating old text (#73).

### Changed
- The version shown in the app (status bar, menu bar, canvas, About) now comes from one place, so it always matches the release.

### Known issues
- Syntax errors only for Python and Rust without a language server: type and import errors still need pylsp or rust-analyzer. Go, C/C++ and other languages still need their language server to fahh.

See the [full docs](https://fahhide.duckdns.org/docs.html).

## Fahh Editor v0.7.0

Small things that add up: format on save, git change bars, clickable errors in the terminal, and an Explorer that finally shows your dotfiles.

### Install

```powershell
# Windows (PowerShell)
irm https://fahhide.duckdns.org/install.ps1 | iex
```

```bash
# macOS (installs Fahh Editor.app) and Linux x64 (AppImage as ~/.local/bin/fahh, plus an app-menu entry)
curl -fsSL https://fahhide.duckdns.org/install.sh | bash
```

### New
- **Format on save**, **trim trailing whitespace** and **insert final newline** (Settings > Editor). Formatting uses the editor's own formatter, or black, rustfmt, gofmt or prettier when installed, on what is in the editor (#105).
- **Git change bars** in the gutter: added, changed and deleted lines against the last commit, live while you type (#105).
- **Clickable file locations in the terminal**: compiler errors, test failures and Python tracebacks (`app.py:12:5`, `File "x.py", line 3`) open at that line. Drop files onto a terminal to type their paths (#105).
- **Explorer shows dotfiles** (.env, .github, .gitignore) and deep folders; it still skips .git, node_modules and target (#105).
- **Editor options**: sticky scroll, bracket pair colours, font ligatures, relative line numbers, Alt or Ctrl multi-cursor (#105).
- **Zoom** the whole window with Ctrl+= and Ctrl+- (Ctrl+0 resets) (#105).
- **Breadcrumbs** list a folder's files when clicked (#105).
- **Fahh Local prompt history**: Up and Down bring back earlier prompts (#105).

### Fixed
- **Debug Console** split program output across lines ("hello fahh" / "42"); it now shows lines as the program printed them (#105).

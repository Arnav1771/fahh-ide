## Fahh Editor v0.8.4

Linux fix: the AppImage opens properly again on newer distributions and WSL, and git push works from inside it.

### Install

```powershell
# Windows (PowerShell)
irm https://fahhide.duckdns.org/install.ps1 | iex
```

```bash
# macOS (installs Fahh Editor.app) and Linux x64 (AppImage as ~/.local/bin/fahh, plus an app-menu entry)
curl -fsSL https://fahhide.duckdns.org/install.sh | bash
```

### Fixed
- **Linux AppImage opened a blank window** on newer distributions such as Ubuntu 26.04 and on WSL ("Could not create default EGL display: EGL_BAD_PARAMETER"). The AppImage bundled an old libwayland-client that newer Mesa can't load; Fahh now uses the system copy. (#153)
- **git push failed inside the AppImage.** Git, the terminal and language servers no longer load Fahh's bundled libraries.

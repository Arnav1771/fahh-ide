## Fahh Editor v0.9.0

Startup script 5.3 MB to 0.95 MB, a terminal look for fahh agent, Fahh Local Chat for VS Code, and offline fonts.

### Install

```powershell
# Windows (PowerShell)
irm https://fahhide.duckdns.org/install.ps1 | iex
```

```bash
# macOS (installs Fahh Editor.app) and Linux x64 (AppImage as ~/.local/bin/fahh, plus an app-menu entry)
curl -fsSL https://fahhide.duckdns.org/install.sh | bash
```

## What's new in 0.9.0

- **Faster start:** the startup script shrank from 5.3 MB to 0.95 MB; panels and dialogs you rarely use load when you open them.
- **`fahh agent` in a terminal** now looks like a proper terminal app: a welcome box, tool calls with results, coloured diffs in approvals.
- **Fahh Local Chat** (VS Code extension, 0.3.1): slash commands, every provider, a real chat, and it updates itself.
- **Fixed:** hovering in Explorer could keep dragging a file after a missed mouse release; startup font and sound errors are gone; fonts now work offline.

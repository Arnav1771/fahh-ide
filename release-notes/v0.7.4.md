## Fahh Editor v0.7.4

Notebooks now run in order and can write code for you, Roundtable shows pictures, and Fahh Local can no longer save a half-written file.

### Install

```powershell
# Windows (PowerShell)
irm https://fahhide.duckdns.org/install.ps1 | iex
```

```bash
# macOS (installs Fahh Editor.app) and Linux x64 (AppImage as ~/.local/bin/fahh, plus an app-menu entry)
curl -fsSL https://fahhide.duckdns.org/install.sh | bash
```

### Added
- **✨ Generate code in notebooks.** Describe the cell you want; Fahh Local writes it into a new cell below, typing as it streams, with Stop, then Run, Regenerate or Discard. It reads the cells above and, if a kernel is running, the live variables (a DataFrame's columns and types, imports), so the code uses your real names. Nothing runs by itself (#119).
- **Edit notebook code cells in place.** Click a cell, edit, and it saves into the `.ipynb` (#119).
- **Pictures in the Roundtable panel:** see them as thumbnails (click for full size) and share them by pasting, dragging in or attaching. Up to 4 per note, 5 MB each (#117).

### Fixed
- **Run all ran notebook cells out of order**, so a later cell could hit `NameError` before the data existed and stop the run. Cells now always run top to bottom (#119).
- **Fahh Local could save a cut-off file and mark it done** when a model ran out of output mid-file (seen as a broken `.ipynb`). A cut-off step is now refused and the model is asked to write in smaller parts; `.json` and `.ipynb` files are checked before they're written (#116).
- The "Not valid notebook JSON" message explains why and offers **Open source at line N** (#116).

## Fahh Editor v0.8.8

Switching sessions keeps agents working, and Fahh Local now runs inside VS Code too.

### Install

```powershell
# Windows (PowerShell)
irm https://fahhide.duckdns.org/install.ps1 | iex
```

```bash
# macOS (installs Fahh Editor.app) and Linux x64 (AppImage as ~/.local/bin/fahh, plus an app-menu entry)
curl -fsSL https://fahhide.duckdns.org/install.sh | bash
```

### Added
- **Fahh Local for VS Code.** A side-bar chat that runs this release's agent in your workspace, with Allow / Always / Deny on every edit and command. It needs this version (0.8.8) installed.
- **`fahh agent --json`**, the machine interface the extension uses.

### Fixed
- **Switching sessions no longer stops the agent.** It keeps working in the background; the sidebar shows Working / Needs your OK / Done, with a notification when it finishes.
- Selecting text in a reply no longer highlights the composer.

### Security
- cookie 0.18.3 and url 2.5.9 (RUSTSEC-2026-0594, RUSTSEC-2026-0592).

## Fahh Editor v0.8.7

Fahh opens on Fahh Local with recent sessions from every folder; current Claude models get their full 1M context.

### Install

```powershell
# Windows (PowerShell)
irm https://fahhide.duckdns.org/install.ps1 | iex
```

```bash
# macOS (installs Fahh Editor.app) and Linux x64 (AppImage as ~/.local/bin/fahh, plus an app-menu entry)
curl -fsSL https://fahhide.duckdns.org/install.sh | bash
```

### Added
- **Agent home with every folder's sessions.** Fahh opens on Fahh Local with your recent sessions from all folders, plus View all. The sidebar switches between All folders and This folder, and opening a session from another folder opens that folder for you. Turn it off under Settings > Startup.

### Fixed
- **1M context for current Claude models.** Opus/Sonnet 4.6 and later, the 5 family and Fable were treated as 200K, so conversations compacted far too early.
- **Update button on the same day.** The update check now runs at launch and every few hours instead of once a day.

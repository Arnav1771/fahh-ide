## Fahh Editor v0.8.3

Smoother: no more window freezes, cleaner language servers, and notebook keys that work.

### Install

```powershell
# Windows (PowerShell)
irm https://fahhide.duckdns.org/install.ps1 | iex
```

```bash
# macOS (installs Fahh Editor.app) and Linux x64 (AppImage as ~/.local/bin/fahh, plus an app-menu entry)
curl -fsSL https://fahhide.duckdns.org/install.sh | bash
```

### Security
- **Workspace trust.** The first time you open a folder, Fahh asks whether you trust it. Until you do, it won't run the folder's own Python (`.venv`), start language servers that execute project code, or run its tasks. The status bar shows "Restricted"; change it any time with "Manage Workspace Trust".
- A project's `.fahh/permissions.json` can no longer pre-approve the agent's commands; "always allow" answers now live only in your own app data. Rules you saved in a project before will be asked once more.
- Run can no longer be tricked by file names: names like `a$(cmd).py` are passed safely on Windows, macOS, Linux and in WSL folders.
- Stop only stops runs Fahh started, and quitting Fahh (or a crash, on Windows) ends every program it launched: runs, language servers, debug adapters, formatters and agent commands.
- Tighter app permissions and a content security policy; the clipboard no longer asks for permission inside Fahh's own window.
- Updated dompurify and markdown-it, which had known vulnerabilities.

### Security
- Fixed 9 known vulnerabilities in Fahh's Rust dependencies (zlib, rustls-webpki, webpki-roots, plist, zip); every build is now checked with cargo audit.

### Fixed
- Search, replace, the file tree and git status no longer freeze the window while they run.
- Language servers: one per window and language, no duplicates when several start at once, and closing a window ends its own language servers, runs and kernels while other windows keep theirs.
- Notebook keys A, B, M, Y and Alt+Up/Down act on the selected cell, also while another cell is running; clicking a cell no longer runs it.
- Kotlin Run on Windows is covered by tests on a Windows build machine.

      [FAQ]

      Asked, loudly.

      What is CATE Spatial Canvas Mode?

      Press Ctrl + Shift + C to unlock an infinite 2D canvas workspace inspired by CATE. Code editors, terminals, AI agents, and browser previews float as draggable, resizable nodes with an interactive radar minimap, freeing you from traditional single-file tab overload.

      How does the AI Composer work?

      Press Ctrl + I to open Cursor Composer. It plans and executes multi-file modifications across your workspace with @file, @folder, and @codebase context tags. Review clean unified diffs before accepting with Ctrl + Enter.

      Does it really play on every error?

      On every error-severity diagnostic, at most once per cooldown window. The window is 3 seconds by default and set by sfx_cooldown_secs in ~/.fahh/config.json. Warnings, information and hints never play.

      Can I turn the cooldown off?

      Set sfx_cooldown_secs to 0 and every error message plays. Choose 0 in the simulator above to hear what that is like.

      Is it Electron?

      No. The shell is Tauri 2: a lightweight Rust core and the operating system's native web view, paired with Monaco Editor for high performance.

      Which AI models can I use?

      Any model you want. Connect locally to Ollama or LM Studio with zero telemetry, or enter an API key for OpenRouter, Groq, or OpenAI. No keys are bundled and your code never leaves your computer unless you explicitly ask.

      Why does my system warn about the installer?

      The builds are not code-signed yet. Signing requires a paid developer certificate; until then Windows SmartScreen and macOS Gatekeeper will prompt before first launch. The source code and GitHub Actions build pipelines are 100% public and verifiable.

# Agent Mode

The **Agent | Editor** switch at the top left changes the whole window between the code editor and a full-window **Fahh Local** chat.

---

## Agent mode

- Your chat sessions are listed on the left. Click one to resume it, or start a new one.
- `Ctrl+Shift+A` searches sessions by title and content.
- The open folder stays the agent's workspace: edits it makes show up when you switch back to Editor.
- `Ctrl+Shift+P` (command palette) works in both modes.

## Fahh Local features

- **Modes:** Ask, Auto-edit, Plan.
- **Slash commands:** type `/` in the input for the list, including `/loop` (repeat a prompt) and subagents for parallel work.
- **Approvals:** file edits and commands ask first unless you are in Auto-edit.
- **`@` mentions** attach files and folders.

See [Fahh Local Agent](Fahh-Local-Agent) for providers and models.

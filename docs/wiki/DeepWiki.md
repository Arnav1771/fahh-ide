# DeepWiki

Right-click any symbol in the editor and choose **See Wiki** (or run **DeepWiki: See Wiki for Symbol at Cursor** from the command palette). The DeepWiki view shows:

1. **Definition:** where the symbol is defined, with a click to jump there.
2. **Documentation:** its doc comment or docstring.
3. **Usages:** every place in the workspace that uses it.
4. **AI explanation:** a short write-up from your configured Fahh Local model of what the symbol does and how it is used.

The first three work offline. The explanation needs a model set up in Fahh Local.

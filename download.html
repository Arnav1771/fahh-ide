Windows

your system

x64 // Windows 10 and 11 // WebView2

  • Installer (.exe)3.0 MB
  • Windows Installer package (.msi)4.5 MB

SmartScreen shows "Windows protected your PC": choose More info, then Run anyway. The .exe installs for your user account only, without administrator rights.

macOS

your system

Apple silicon and Intel // .dmg

  • Apple silicon (.dmg)4.5 MB
  • Intel (.dmg)4.7 MB

Gatekeeper blocks the first launch of an unsigned app: right-click Fahh Editor in Applications, choose Open, then Open again.

Linux

your system

x86_64 // needs WebKitGTK 4.1

  • AppImage78.8 MB
  • Debian and Ubuntu (.deb)4.9 MB
  • Fedora and RHEL (.rpm)4.9 MB

The AppImage bundles its libraries, which is why it is larger. The .deb and .rpm use the system's WebKitGTK.
